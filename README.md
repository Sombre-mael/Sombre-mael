# Sombre Mael

Développeur web et mobile basé à Lubumbashi, je construis des interfaces modernes et des produits numériques pensés pour répondre à des besoins concrets.

Je m’intéresse particulièrement aux projets qui combinent technologie, design, stratégie et utilité réelle. Pour moi, un bon produit ne se limite pas à fonctionner : il doit être clair, agréable à utiliser, bien structuré et capable d’apporter de la valeur.

Je travaille principalement avec React, Next.js, TypeScript, React Native et Expo. J’avance aussi sur l’intégration backend avec Supabase, Laravel et d’autres outils qui permettent de transformer une idée en application complète.

---

## Ce que je fais

Je conçois et développe des solutions numériques autour de plusieurs axes :

* applications web modernes ;
* applications mobiles avec React Native et Expo ;
* sites vitrines professionnels ;
* interfaces utilisateur propres et responsive ;
* back offices et tableaux de bord ;

## Ma manière de construire

J’aime travailler avec une logique de produit.

Avant de coder, je cherche à comprendre le besoin, l’utilisateur, le contexte et la valeur que le projet doit apporter. Ensuite, je structure les fonctionnalités, l’interface et l’architecture avant de passer au développement.

Je fais attention à trois choses :

```txt
Clarté        Un projet doit être simple à comprendre.
Utilité       Une fonctionnalité doit répondre à un vrai besoin.
Présentation Une interface doit inspirer confiance.
```

Je préfère construire progressivement une base propre plutôt que multiplier les fonctionnalités sans direction claire.
